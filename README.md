# 工作资料库

这是正式版“工作资料库”。它将原料积累、资产加工、人物关系、故事开发、SOP、流水线执行和结果入库完整串联。

## 第九阶段新增

- 新总览工作台：汇总工作资料库健康度、待处理事项和最近产出。
- 五项闭环检查：已确认资产、人物关系、章节卡、已验证 SOP、流水线入库。
- 待办自动计算：待加工灵感、待确认资产、待审核流水线、空项目和待验证 SOP。
- 一键导出当前账号完整 JSON 备份，不包含密码和数据库密钥。
- 保留第一至第八阶段全部功能，界面标记为 1.0 正式版。

## 1.0 日常使用顺序

1. 在灵感原料库随手记录种子。
2. 加工成规则卡、人物卡、情节卡或场景卡，并人工确认。
3. 建立人物关系与故事项目，逐章拆分起承转合和钩子。
4. 把有效方法沉淀成 SOP。
5. 在自动化流水线中组合项目、SOP 和已确认资产，复制执行指令给 Codex。
6. 把结果粘贴回来审核，转为资产、章节卡或 SOP。
7. 定期在总览页检查待办并导出备份。

## 发布

1. 在 Supabase 项目的 SQL Editor 中运行 `supabase-schema.sql`。
2. 将本文件夹全部文件上传到 GitHub 仓库根目录并覆盖旧版。
3. 等待 GitHub Pages 自动更新。

旧表和旧数据不会被清空。若已经成功部署第八阶段，本次不需要重新运行 SQL；直接覆盖 GitHub 文件即可。首次安装则仍需运行完整 `supabase-schema.sql`。

安全说明：配置文件只包含浏览器可公开使用的 publishable key；数据库启用了行级安全，每个账号只能访问自己的素材。切勿上传数据库密码、Secret key 或 service_role key。
