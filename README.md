# 暗黑玄幻内容银行

这是第八阶段“执行结果自动入库”升级包。在第七阶段流水线执行台的基础上，把 Codex 或人工执行结果转换成可继续使用的内容资产。

## 第八阶段新增

- 流水线结果可转换成规则卡、人物卡、情节卡或场景卡，默认进入“待确认”。
- 故事开发结果可转换成章节卡，并自动识别“开篇钩子、起、承、转、合、章尾钩子、情绪曲线、连续性检查”。
- 经过验证的方法可转换成 SOP，默认进入“测试中”。
- 每次转换保留来源流水线、目标类型、目标名称和时间，支持追溯。
- 一条流水线可以沉淀多个资产，不覆盖原始执行结果。

说明：当前版本的“自动识别”是根据规范化标题提取字段，因此给 Codex 的输出要求越标准，章节卡和 SOP 的预填越完整；入库前仍由你人工确认。

## 发布

1. 在 Supabase 项目的 SQL Editor 中运行 `supabase-schema.sql`。
2. 将本文件夹全部文件上传到 GitHub 仓库根目录并覆盖旧版。
3. 等待 GitHub Pages 自动更新。

旧表和旧数据不会被清空；本次新增 `pipeline_conversions` 来源记录表，并给资产卡、章节卡和 SOP 增加可选的流水线来源字段。

安全说明：配置文件只包含浏览器可公开使用的 publishable key；数据库启用了行级安全，每个账号只能访问自己的素材。切勿上传数据库密码、Secret key 或 service_role key。
