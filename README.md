# 暗黑玄幻内容银行

这是第七阶段“自动化流水线执行台”升级包。在第六阶段模板与 SOP 的基础上，新增四类可执行任务：市场风向扫描、素材自动加工、故事开发、连续性质检。

## 第七阶段新增

- 创建流水线任务，并关联故事项目与 SOP。
- 自动生成五步执行清单，记录待执行、执行中、待审核、已完成或失败状态。
- 生成包含项目设定、SOP 和已确认资产的完整 Codex 执行指令，一键复制使用。
- 将 Codex 输出粘贴回内容银行，填写人工审核意见后归档。
- 所有流水线数据继续使用 Supabase 私有保存和行级安全。

说明：当前版本不会在浏览器中伪装成“自动 AI”。真正的 AI 执行仍由 Codex 完成；平台负责组织输入、跟踪步骤、保存结果和人工审核。后续阶段再接入受控的服务端执行器。

## 发布

1. 在 Supabase 项目的 SQL Editor 中运行 `supabase-schema.sql`。
2. 将本文件夹全部文件上传到 GitHub 仓库根目录并覆盖旧版。
3. 等待 GitHub Pages 自动更新。

旧表和旧数据不会被清空；SQL 使用 `create table if not exists`，本次只新增 `pipeline_runs` 表及对应安全策略。

安全说明：配置文件只包含浏览器可公开使用的 publishable key；数据库启用了行级安全，每个账号只能访问自己的素材。切勿上传数据库密码、Secret key 或 service_role key。
